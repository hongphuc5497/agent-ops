# Patterns

## Working Patterns

- One active owner reduces merge and context overhead.
- Markdown decisions beat hidden chat history.
- Tiny scripts are enough until repetition proves otherwise.
- Use Augment for map/impact before risky edits.
- Use OpenClaw to cut scope, not to add features.

## Failure Patterns

- New repo before pain is clear.
- Automation before manual success.
- Multiple agents editing one concern.
- Building platform surfaces before a narrow product wedge.
- Calling research "progress" without a ship artifact.
